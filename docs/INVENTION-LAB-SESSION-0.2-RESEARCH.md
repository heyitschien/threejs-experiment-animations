## 3. Assembly Harness

- **Task and implementation.** Pydantic `AssemblyTask` carries component IDs, sources, optional initial transform, ordered placements, constraints and outputs. `Transform` is position plus axis/angle in degrees. The main `cad_asm` CLI supports `init`, `step`, `verify`, `export` and review/image commands. The solver path uses the first applicable constraint, with absolute, face, distance and coaxial modes. The transform conversion is best-effort and falls back to +Z for a degenerate skew-axis extraction, relevant near 180°. The checkpoint is written before interference review. The main `verify` reports state counts and returns zero for an initialized workspace even when pending/in-review/error counts exist. Treat its state and geometry verdict as distinct. Adopt neither its exit code nor its default transforms as proof of a solved multi-constraint system. ## 4. CADGenBench

- **Scoring architecture.** The raw STEP/B-rep goes through validity, watertightness and tessellated closed-manifold checks. Size, triangle and subprocess-time guards bound native processing. Evaluation distinguishes invalid, missing and valid fixture outcomes and may finish with a result document for an invalid candidate. Shape similarity combines surface-distance F1 with volumetric IoU. Topology compares Betti numbers for connected bodies, handles and voids. Interface metrics use keep-in/keep-out sub-volumes and grouped tolerances. The scorer aligns shapes and its interface scorer allows a bounded pose search. Useful for relative geometry quality, those operations can erase the signed assembly error we must catch. Require an unaligned pass first and preserve the independent axes. ## 5. Proposed two-component hinge benchmark

**Fixture HNG-001 v1.** Freeze this spec and its own reference artifacts before any candidate runs. Geometry is a digital pin/eye joint with one integrated pin and no separate fastener. It checks placement, geometry retention and interference; manufacturability, assembly insertion, strength, loads, friction and physical fit are outside the claim.

### Authoritative local geometry

Use millimetres, column vectors and a right-handed Z-up frame. A box lists closed X/Y/Z ranges, and each cylinder is centered on local `x=y=0` with its listed Z interval. Fuse unions and remove external splits without healing away design features. Local component origins are configured at the intended common axis and both poses at zero are identity.

| ID | Definition and expected local bounds |
| --- | --- |
| `hinge.fixed_leaf` | Fuse backbone box `[-32,-8] × [-2,2] × [0,24]`, two bridge boxes `[-9,-3.5] × [-2,2]` over Z intervals `[0,6]`, `[18,24]`, two radius-5 collar cylinders over those same intervals, and a radius-3 pin cylinder over `[5.5,18.5]`. Pin lies within the collars at its ends and is exposed over `[6,18]`. Bounds `[-32,5] × [-5,5] × [0,24]`. Fixed signed vertex `(-32,-2,24)`. |
