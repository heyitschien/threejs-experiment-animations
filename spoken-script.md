## OCTO · Agent-operated 3D

Ock-toh started as a procedural robotic octopus in Three Jay Ess.

This case study tests a specific engineering workflow.

Can a coding agent use professional authoring software, produce a reproducible asset, bring it into a browser, and leave enough evidence for someone else to evaluate it?

The concept image is the visual reference.

## Study A · Asset integration

The first study kept the existing scene and replaced one foreground arm behind a You Are El option.

Blender's bundled Python generated the geometry and exported a Gee El Bee.

From a clean checkout, the regenerated file matched the original byte for byte.

The browser runs Three Jay Ess and loads the model file locally.

## Study A · Actual deformation

The browser moves the imported mesh along the original procedural path.

Here the left arm is the original and the right is Blender authored.

The revised Playwright test reads the actual positions and normals at three poses.

It also checks that the root stays attached, that the readable label matches the active mode, and that a malformed file preserves the default.

## Study A · Tradeoffs

The Blender variant adds three draw calls and just over six thousand scene triangles in this test.

The extra armor reads most clearly in close-up.

Mobile emulation uses the same desktop hardware, so the frame timing does not tell us how a real phone would behave.

The Blender arm stays optional, which limits the impact of those unknowns.

## Study B · Controlled material comparison

The second study evaluates material design separately.

A static section has fitted metal plates, suckers recessed into the surface, internal ribs, and light channels.

Both Cycles renders show the same geometry under the same camera and lighting.

Only the shell material changes.

On the left, light and visible internals reveal depth.

The opaque control on the right hides them.

## Study B · Browser evidence

The Web Gee El version also shows the layers, with a simpler reflection and transmission treatment.

That demonstrates an inspectable three dimensional material sample.

The Blender camera orbit moves around the static piece.

There is no evidence yet that this transparent construction bends convincingly, or that it is practical in a full animated browser scene.
